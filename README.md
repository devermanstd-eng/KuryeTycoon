# Kurye Tycoon

Wolt benzeri bir kurye şirketini yönettiğin 2D tycoon oyunu (Unity prototip).

Bu repo, Unity projesinin `Assets/KuryeTycoon` klasörüdür.

## İlk kurulum
```bash
cd <UnityProjen>/Assets
git clone https://github.com/devermanstd-eng/KuryeTycoon.git KuryeTycoon
```
Sonra `KURULUM.md` dosyasındaki adımları izle (boş GameObject → `GameBootstrap` ekle → Play).

## Güncelleme
```bash
cd <UnityProjen>/Assets/KuryeTycoon
git pull
```
